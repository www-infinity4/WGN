# WGN Classic TV

Chicago-style classic television channel built from the Infinity channel skeleton.

- Viewer-local daily reset at 12:00 AM
- Classic television through the day
- Nightly movie blocks at 6 PM, 8 PM, and 10 PM
- Live join, start-over, rewind, guide, share + StarCoin progress
- Dedicated Open Graph / X preview artwork

Official/licensed embeddable video is connected only where verified. Guide slots without a cleared embed remain visible without pretending an unofficial upload is licensed.
